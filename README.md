# Data Science Mini Project: Titanic Survival Analysis

This repository contains my capstone mini-project for **Module 05** of my Data Science Virtual Internship.

## 📌 Project Overview
An end-to-end Exploratory Data Analysis (EDA) on the real-world Titanic passenger dataset to uncover key survival factors through data cleaning, statistical aggregation, and visual storytelling.

## 🔍 Key Insights Discovered
- **Gender Factor:** Female passengers had a ~74% survival rate compared to ~19% for male passengers.
- **Socioeconomic Class:** 1st Class passengers experienced the highest survival rate (~63%), significantly higher than 3rd Class (~24%).
- **Age Demographics:** Children under 10 had higher survival probabilities across classes.

- **Matplotlib & Seaborn** (Data Visualization & Heatmaps)
